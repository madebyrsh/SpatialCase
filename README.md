
# SpatialCase

SpatialCase is a visionOS project for exploring virtual iPhone case try-ons using Object Tracking on Apple Vision Pro.

The project aims to recognize and track a physical iPhone 17 and overlay virtual case models onto the tracked device, allowing users to preview different case colors directly on their physical iPhone.

## Goal

- Recognize and track a physical iPhone 17
- Overlay a virtual iPhone case onto the tracked device
- Preview different case colors in real space

## Tech Stack

- visionOS 27
- SwiftUI
- RealityKit
- ARKit
- Reality Composer Pro 3
- Create ML Object Tracking

# SpatialCase

SpatialCase는 Apple Vision Pro의 Object Tracking을 활용해 실제 iPhone 위에서 가상의 케이스를 체험하는 visionOS 프로젝트입니다.

실제 iPhone 17을 인식하고 추적한 뒤, 추적된 기기 위에 가상의 케이스 모델을 정합하여 다양한 케이스 색상을 실제 iPhone 위에서 미리 확인하는 것을 목표로 합니다.

## 목표

- 실제 iPhone 17 인식 및 추적
- 추적된 기기 위에 가상 iPhone 케이스 정합
- 현실 공간에서 다양한 케이스 색상 미리보기

## 기술 스택

- visionOS 27
- SwiftUI
- RealityKit
- ARKit
- Reality Composer Pro 3
- Create ML Object Tracking
